## 에셋 작업 메모

- 다운로드 후 ffmpeg로 loop 편집 + 최적화 (720p, 15fps, ~1MB 목표)
- Sunny: 밝은 배경 → `mix-blend-mode: multiply` 그대로 사용
- Rain: 어두운 배경 → `mix-blend-mode: screen` 또는 `overlay` 검토
- Moonlight: stock 부족 시 Runway Gen-3로 "moonlight rays through greenhouse glass" 생성
