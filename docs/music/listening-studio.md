# 감상 작업실

정적 GitHub Pages의 `/music-tiers/studio/`에서 2026년 10월 감상 목록을 관리합니다. 공개 감상 페이지(`/music/tiers/`)의 **감상 작업실** 링크로 들어갑니다. 자켓과 제작진 정보는 공개 페이지 상세와 검색에서도 확인할 수 있습니다.

## 데이터와 저장

- `src/data/kpop-months.json`이 발매곡과 `details` 메타데이터의 원본입니다. 빌드 전 `scripts/music/build-listening-studio.mjs`가 작업실용 10월 JSON을 갱신합니다.
- `src/data/kpop-listening.json`은 공개 감상 목록입니다. 작업실을 방문하거나 저장해도 공개 감상 목록이 바뀌지 않습니다.
- 자켓은 `public/music-tiers/studio/assets/covers/`에 포함됩니다. 기존 블로그의 자켓을 재사용한 경우 `details.coverProvenance`에 구분합니다.
- 자동 저장은 이 브라우저의 `bunnyside:listening:2026-10:v1`에 보관됩니다. 이전 공개 보드의 `greenhouse:kpop:v2:2026-Q4` 기록은 새 작업실의 첫 방문에 10월 곡만 복사합니다. 기존 분기 기록은 변경하지 않습니다.
- 다른 기기에서는 백업 JSON이나 공유 링크로 복원합니다. 링크에는 선택·티어·한줄평·메타데이터·작업 이력이 들어가며, 가져오기 전에 미리보기를 보여줍니다. 압축 링크가 잘리면 백업 파일을 이용하세요.
- 다른 탭이 작업을 저장하면 덮어쓰기를 멈추고 최신 저장본 또는 백업을 선택하도록 안내합니다. 저장 공간 오류 시 백업을 권합니다.

## 검수와 내보내기

선택한 곡의 티어·한줄평·검수를 완료하고 오류를 확인한 뒤 공개용 파일을 내보냅니다. 원본에서 찾지 못한 크레딧과 제공처 요청 제한은 참고 경고로 구분하고, 추정해서 채우지 않습니다. 자켓·제작진 보완 내용은 백업과 메타데이터 JSON에 포함되며 선택한 곡의 정보는 Markdown에도 들어갑니다.

기존 `curated.mjs`와 `scripts/music/import-kpop-ratings.mjs`가 받는 `{v:2,period,rows,notes}` 형식은 그대로입니다. 이 파일의 반영은 분기 전체를 교체하므로 다른 월의 공개 감상곡이 있는 경우 먼저 합쳐야 합니다. 작업실의 10월 메타데이터 파일을 기존 월 목록에 병합할 때도 다른 월은 유지하세요.

## 제작진 정보 수집 현황

2026-11-10 기준 자켓 116곡, 곡 상세 45곡(작곡 44·작사 44·편곡 42곡)을 확보했습니다. 71곡은 제공처의 HTTP 429 요청 제한으로 `pending`입니다. 곡별 사유는 [수집 보고서](./listening-studio-collection.md)에 있습니다. 이 배포에는 사용자의 감상 평가를 임의로 넣지 않았습니다.

## 토큰과 호스팅

GitHub 수집본 다시 읽기는 공개 GET 요청만 사용합니다. 필요한 경우에만 Contents: read 토큰을 입력하며 입력·요청 메모리에서만 사용하고 저장·공유·URL·로그에 포함하지 않습니다. 성공/실패 시 입력란을 비우며 401/403/404와 시간 초과의 재시도를 안내합니다. 원격 쓰기·브랜치 생성·자동 공개 발행 기능은 없습니다.

서비스 백엔드와 추가 호스팅은 사용하지 않습니다. iPhone Safari 실기기 검증은 아직 수행하지 않았습니다.
