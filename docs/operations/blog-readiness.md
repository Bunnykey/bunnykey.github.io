# 블로그 사용성 완료 기준

목표: iPhone을 포함한 작성자가 글·사진·임베드를 작성하고, 실제 화면을 확인하고, 저장/배포 실패를 구분하며 발행할 수 있게 한다. 독자는 모바일에서 글을 찾고 읽을 수 있어야 한다. Astro와 기존 GitHub Pages를 유지하고 추가 호스팅은 만들지 않는다.

## 사용 경로

사이트 하단 **글쓰기** → 글 형식 선택 → Pages CMS에서 작성·사진 추가 → 초안 저장 → 필요할 때 공개 미리보기 선택 → 배포 상태 확인 → 실제 Astro 미리보기 → 초안 해제·저장 → 배포 완료 → 공개 글 확인.

`/write/`를 iPhone 홈 화면이나 즐겨찾기에 등록할 수 있다. CMS 로그인은 Pages CMS가 처리하며 이 블로그는 비밀번호나 GitHub 토큰을 받지 않는다.

## 자동 검증 기준

| 사용자 작업 | 구현/판정 근거 |
|---|---|
| 형식 선택 후 작성 시작 | 세 컬렉션의 Pages CMS 새 글 링크, 한국어 안내, 오류 도움말 |
| 공개 전 실제 화면 확인 | 명시적으로 공유한 초안만 `/preview/`에서 공용 글 템플릿으로 렌더링 |
| 사진·임베드 확인 | 실제 Astro 빌드 및 브라우저의 이미지 로드·세 제공자 출력 검사 |
| 저장과 배포 구분 | 배포 대기·완료·캐시된 이전 화면·실패·조회 제한을 구분하는 수동 상태 확인 |
| 미리보기 공유 중지/발행 | 재빌드 후 이전 미리보기 파일 제거와 공개 경로 전환 검사 |
| 기본 초안 보호 | 기본 공개 미리보기 꺼짐, 일반 HTML/OG/목록/RSS/시리즈/검색/사이트맵 제외 검사 |
| 폰에서 읽기 | WebKit iPhone 13 설정과 Chromium에서 메뉴·테마·가로 넘침·검색·글 읽기 검사 |
| 검색 오류 복구 | Pagefind 로드 실패 → 안내 → 재시도 → 실제 검색 결과 검사; 테스트에서 수동 초기화하지 않음 |
| 태그 선택·이동 | 숨긴 글의 레이아웃/키보드 포커스 제외, URL/새로고침 복원, 현재 메뉴 갱신 검사 |
| 기존 글·확장성 유지 | 기존 MD/MDX·Notion·로컬 초안/발행/충돌 테스트, 공용 글 렌더러 사용 |
| 끊어진 링크 예방 | 매 빌드에서 모든 생성 HTML의 내부 링크·이미지·스크립트·스타일 파일 검사 |

실행:

```bash
npm ci
npm test
npm run build
python3 scripts/verify_dist.py dist
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

PR의 `Validate changes`가 위 검증을 실행한다. 브라우저 검증은 운영 원본을 수정하지 않고 임시 사이트에만 테스트 글을 만든다. 테스트 보고서·스크린샷은 Actions의 `browser-results`에 7일간 보관한다. 자동화된 WebKit 검사를 실제 iPhone Safari 수용시험으로 표시하지 않는다. 외부 플레이어는 브라우저 테스트에서 요청을 대체하므로 실제 재생 성공을 뜻하지 않는다.

## 계정·실물 단말에서 필요한 수용시험

다음 항목까지 확인해야 전체 목표를 완료로 판정한다. 저장소/빌드 테스트만으로 완료 처리하지 않는다.

- [ ] Pages CMS의 실제 GitHub 로그인과 이 저장소 편집 권한 확인
- [ ] 테스트용 작업 브랜치에서 iPhone 한글 작성·수정·사진 선택/업로드
- [ ] 초안 저장 후 닫기·재접속·본문/사진/메타데이터 유지 확인
- [ ] 미디어 생성 도우미 → CMS Source 저장 → 세 임베드 보존 확인
- [ ] 실제 iPhone에서 공개 미리보기의 레이아웃·사진·플레이어 재생 확인
- [ ] 사용자가 공개해도 되는 글의 main 저장 커밋 → 해당 Pages 배포 완료 → 운영 글/사진 확인
- [ ] 미리보기 공유 중지와 공개 글 수정 시 기존 글 유지 절차 확인

권한이 없거나 로그인 화면에서 막히면 그 단계를 대기 상태로 남긴다. 저장소 권한을 임의로 확대하거나 비밀번호를 채팅에 요청하지 않는다. 테스트 때문에 기존 공개 글을 수정하거나 검증용 글을 운영에 발행하지 않는다.

## 지원 범위

- 추가 호스팅 없는 정적 사이트다. 미리보기 생성에도 GitHub Pages 배포 시간이 필요하다.
- 공개 미리보기는 비공개 링크가 아니다. 기본 초안도 공개 GitHub의 원본과 이미지까지 숨기지는 않는다.
- Pages CMS와 로컬 편집기 사이에는 공통 실시간 잠금이 없다. 같은 글을 동시에 편집하지 않고 도구 전환 시 Git 원본을 갱신한다.
- Notion은 import-only다. Git 소유 글을 덮어쓰거나 Notion으로 역동기화하지 않는다.
- MDX/복잡한 HTML은 로컬/Git 편집 경로를 유지한다.

자세한 작성 절차와 복구 방법은 [Pages CMS 사용법](pages-cms.md), 저장·충돌 규칙은 [발행 계약](../architecture/publishing-contract.md)을 따른다.
