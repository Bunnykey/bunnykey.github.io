# 블로그 기능 진입 경로

- 상단(데스크톱·모바일): 글 · 음악 · 작업실 · 글쓰기 · 소개
- 홈 바로가기: 케이팝 감상 · 감상 작업실 · 글쓰기 · 모든 도구
- `/workbench/`: 음악, 작성·미리보기·배포·미디어 도우미, 하나의 글 목록·검색·RSS, 기존 인터랙티브 데모, 로컬 편집기·Notion 가져오기 사용법
- 음악 메뉴: 공개 티어 페이지. 주제별 메뉴는 없으며 데모는 작업실에서 찾는다.
- 감상 작업실: 블로그 감상 페이지와 모든 도구로 돌아가는 링크
- 글쓰기: 작업실로 돌아가는 링크와 로컬·Notion 연결 안내
- 모든 공용 페이지 하단: 작업실과 케이팝 감상

진입점은 `src/consts/navigation.mjs`에서 관리한다. 새 기능을 추가하면 실제 페이지와 함께 작업실 목록에도 등록한다. 로컬 편집기와 Notion 가져오기는 정적 사이트에서 실행되는 기능이 아니므로 실행 조건과 기존 사용법을 연결한다. CMS 로그인·외부 서비스 권한은 기존 도구가 처리한다.

`npm run build`의 링크 검증은 생성 HTML의 내부 절대·상대 링크, 이미지·스크립트·스타일, 앵커가 실제로 존재하는지 확인한다. 작업실에 등록된 기능은 홈에서 두 번 이내의 클릭으로 도달해야 한다. 존재하지만 블로그 어디에도 연결되지 않은 기능은 빌드 실패로 처리한다.

모바일 메뉴는 숨겼을 때 키보드 포커스를 막고, Escape·메뉴 선택·페이지 이동 시 닫힌다. Astro 화면 전환 후 데스크톱과 모바일의 현재 메뉴 표시를 함께 갱신한다.

2026-11-12: 기존 글 6개 삭제. 홈·모바일 메뉴·CMS·로컬 편집기에서 글 종류와 주제 선택 제거. 이전 형식별 목록 주소는 동일한 전체 글 목록을 보여 주며 noindex/canonical로 중복 노출을 막는다. 내부 저장 계약은 이전 도구 및 백업을 읽을 수 있도록 유지한다.
