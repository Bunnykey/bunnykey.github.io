# 들은 곡 선택과 분기별 케이팝 감상

공개 주소: https://bunnykey.github.io/music/tiers/

전체 발매곡을 보관하는 목록과, 직접 들은 곡을 골라 담은 감상 목록을 분리합니다. 기존 Astro·GitHub Pages를 사용하고 서버나 외부 호스팅을 추가하지 않습니다.

## 데이터의 역할

| 데이터 | 역할 |
| --- | --- |
| `src/data/kpop-months.json` | 월별 곡 ID·제목·아티스트·발매일·커버·음원 링크. 곡을 감상 목록에서 빼도 유지합니다. |
| `src/data/kpop-listening.json` | 분기별로 공개할 `picks`만 저장. 각 항목은 곡 ID, 티어, 한줄평입니다. |
| 브라우저 저장본 | 방문자별 곡 선택·티어·한줄평. 분기 단위로 저장하며 공개본은 변경하지 않습니다. |

분기는 **발매일 기준**입니다. 10·11·12월 발매곡은 `2026-Q4`에 모이고, 원래 발매일은 유지됩니다. 현재 수집본은 2026년 10월 116곡이며, 화면에 수집한 월을 표시합니다. 나중에 11·12월 발매곡을 추가해도 기존 선택은 유지됩니다.

`미평가`는 골라 담았지만 아직 점수를 정하지 않은 곡입니다. 선택하지 않은 곡은 검색 목록에만 있고 티어 보드에는 나오지 않습니다.

## 이용 흐름

1. **곡 골라 담기**를 열고 곡명·아티스트·앨범 또는 발매 월로 찾습니다.
2. 실제로 들은 곡을 체크합니다. 여러 곡을 고른 뒤 **선택 완료**를 누릅니다. 선택은 즉시 브라우저에 자동 저장됩니다.
3. 선택한 곡만 있는 보드에서 티어·순서·한줄평을 정합니다. PC 드래그와 모바일 곡 상세창을 지원합니다.
4. **감상 목록에서 빼기** 또는 곡 선택창의 체크 해제로 보드에서 제외합니다. 원본 곡 정보는 삭제하지 않습니다. 되돌리기로 복구할 수 있습니다.
5. **티어 비우기**는 선택은 유지하고 선택한 곡의 배치만 미평가로 옮깁니다.

블로그 감상 화면에는 블로그가 공개한 곡만 나옵니다. 아직 선택하지 않은 곡을 임의로 들은 것으로 처리하지 않으며, 초기 공개 감상 목록은 비어 있습니다. 기존의 월별 브라우저 저장본이 있으면 평가했거나 한줄평을 작성한 곡을 새 분기 목록으로 복원합니다. 나머지 미평가 곡은 검색 목록에서 다시 고를 수 있습니다.

## 저장과 공유

- 링크에는 선택한 곡과 배치만 포함합니다. 개인 한줄평은 포함하지 않습니다.
- 개인 파일 백업에는 선택·배치·한줄평이 포함됩니다. 목록에서 뺀 곡의 개인 메모도 백업에 보관할 수 있습니다.
- 공개 평가용 파일에는 **현재 선택한 곡의 평가와 한줄평만** 포함합니다. 선택하지 않은 곡의 개인 메모는 제외합니다.
- 다른 사람의 공유 링크를 여는 것만으로 내 저장본이 바뀌지 않습니다. 가져오기 후에도 되돌리기를 지원합니다.
- 파일 다운로드만으로 블로그가 발행되지는 않습니다. 기기 간 자동 동기화와 방문자 투표 집계는 제공하지 않습니다.
- 이미지 저장은 현재 선택한 곡을 대상으로 PNG를 만들며, 실패 시 SVG로 저장합니다.

## 공개 감상 반영

블로그 주인이 사이트에서 공개 평가용 파일을 만든 다음, 아래 명령으로 감상 목록에 적용합니다.

```sh
node scripts/music/import-kpop-ratings.mjs /path/to/kpop-2026-Q4-public-ratings.json
npm test
npm run build
```

새 파일은 `v: 2`, `period: "2026-Q4"`, `rows`, `notes` 형태입니다. 스크립트는 곡 ID·분기·중복 선택·한줄평 길이를 검사하고, **다른 분기의 감상과 전체 발매곡 원본을 유지한 채 해당 분기의 공개 선택만 갱신**합니다. 이전 `v: 1` 월별 평가 파일도 읽을 수 있습니다.

Pages CMS의 **음악 · 발매곡 목록**에서 메타데이터를, **음악 · 공개 감상 목록**에서 공개할 곡 ID·티어·한줄평을 관리할 수 있습니다. 월별 원본의 예전 티어·한줄평 필드는 호환용이며 숨겨 둡니다.

`main` 변경 시 기존 GitHub Pages 워크플로가 검사·빌드·배포를 실행합니다.

## 발매곡 수집

곡별 출처와 수집 범위는 `docs/music/kpop-2026-10-sources.json`에 기록합니다. 현재는 벅스 아이돌 분류와 확인된 국내 유통 앨범에서 타이틀곡을 모은 첫 수집본입니다. OST·리믹스·데모·버전 재발매는 제외했고, 전체 발매의 완전성을 보장하지 않습니다.

신규 월을 추가할 때도 곡 ID를 재사용하지 마세요. ID가 유지되면 기존 선택을 다시 만들 필요가 없습니다. 발매곡의 추가는 들은 곡 선택을 자동으로 늘리지 않습니다.

실제 iPhone Safari에서의 터치·파일 저장·클립보드와 Pages CMS 계정의 발행 조작은 별도 실기기 검증이 필요합니다. 공개 저장소 파일의 비공개 상태는 접근 제어가 아니므로 개인정보를 넣지 마세요.
